## What is NexusVeritas?

NexusVeritas is a behavioral operator intelligence platform for Solana.  
Instead of scoring tokens — we profile the wallets that deploy them.

## Database

- **200,000+** operator profiles
- **8** behavioral archetypes
- **25-dimensional** behavior vectors (pgvector)
- Historical data since 2024

## Archetypes

| Archetype | Description |
|---|---|
| INDUSTRIAL_DEPLOYER | Mass launcher, 500+ tokens, automated cadence |
| ROTATION_OPERATOR | Wallet rotation, identity obfuscation |
| WALLET_FACTORY | Disposable wallets, one token per address |
| PROFESSIONAL_CREATOR | Legitimate long-term builder |
| EXCHANGE_FUNDED_DEPLOYER | CEX-funded, aggressive pattern |
| CASUAL_CREATOR | Low-volume, organic activity |

## Why NexusVeritas

- No AI-generated scores — every signal derived from observable blockchain state
- Explainable risk factors — not just a number
- Deterministic — reproducible results for identical blockchain state
- Behavioral analysis — who acts behind the token
